# v1.22 · 给下游的变更清单

> 这一版对你**有一项要做**（加部署指纹）。另一项是母版侧工具增强，你不用管。

## 1. `_同步.md` 加一节「部署指纹」

**加什么**（放在文件最后）：

```markdown
## 部署指纹（别手改）

| 文件 | 同步时的 SHA256（前 16 位） |
|---|---|
| `AGENTS.md` | <跑下面这句得到> |
```

```powershell
(Get-FileHash -LiteralPath .\AGENTS.md -Algorithm SHA256).Hash.ToLower().Substring(0,16)
```

**它解决什么**：母版推更新前，能判断"`AGENTS.md` 在你这里有没有被改过"——
**改过就该先问，不能直接覆盖**（那会吃掉你的合法修改）。

**为什么只记 `AGENTS.md`**：只给"从骨架复制、且母版将来可能更新"的文件记。
`_本工作区.md`／`_同步.md`／`GLOBAL_WORKFLOW.md`／`任务看板.md` **不要记**——
那是你自己的文件和状态，母版不该碰。

**来源**：Spec Kit 的 install manifest（它用哈希检测本地改动，不符就停下来问）。
