# v1.31 · 给下游的变更清单

> **对你有一项要做**：把真实清单挪到 `已应用工作区.local.md`（如果你要公开仓库）。

## 为什么

母版准备公开到 GitHub，但仓库里原来有 **7 处你的真实绝对路径**：

```
对话测试.md        4 处
已应用工作区.md     3 处  ← 这里列着 杂活 / 软件项目管理 / 科教 的真实路径
```

## 改成什么（两处分开）

| 文件 | 内容 | 进仓库吗 |
|---|---|---|
| `已应用工作区.md` | **只有示例和填法** | ✅ 进 |
| `已应用工作区.local.md` | **你的真实路径** | ❌ **不进**（`.gitignore` 已加 `*.local.md`） |

**`audit.ps1` 和 `sync.ps1` 会合并读两个文件**，所以本地照常工作。

**你要做的**：

```powershell
Copy-Item <规则系统>\已应用工作区.md <规则系统>\已应用工作区.local.md
# 然后只改 .local.md 里的 LIST，填上自己的三个工作区
```
