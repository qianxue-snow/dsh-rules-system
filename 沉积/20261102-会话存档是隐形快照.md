# 会话存档是"隐形的项目快照"

> **来源**：`杂活` 工作区，2026-11-02（一个工程目录被删后，要找回当时的对话与代码）
> **状态**：候选池（证据 1，需要第 2 个下游/第 2 次应验才够升格）

## 什么场景

工程目录已经删了，要找回"当时怎么做的"——对话记录、代码版本。

## 发现了什么

| 层 | 位置 | 活不活 |
|---|---|---|
| **DSH 会话日志** | `~\.dsh\sessions\<编码后的 cwd>\<session-id>\session.v4.jsonl.zstd` | **按 cwd 存，不跟工程目录走**：工程删了，15 个会话 / 52.7 MB 全在，解压就能读 |
| VS Code 本地历史 | `%APPDATA%\Code\User\History` | 按**文件**存，与工程目录无关：捞回 41 个文件 153 个版本（含被删的 Boss 技能类） |
| Claude Code 的 transcript | `~\.claude\projects\<slug>\<id>.jsonl` | **默认 30 天清理**：8 月的全没了，只剩 memory 笔记 |

## 该怎么避免（其实是该怎么利用）

- 删工程前**不必恐慌**——对话和文件历史大概率还在。
- 但**别手删 `~\.dsh\sessions`**：那是唯一一份"工程删了也还在"的记录。
- 依赖 Claude 侧留档不可靠：要留就自己导出。
- 解压口径：`zstandard` 流式解压后按行 JSON 解析；脚本见 `杂活\任务\2026-11-02-简历实习经历完善\work\`（`extract.py` / `export_history.py`）。

> **判据**（能不能进母版）：去掉"杂活"这个名字，换成任何工作区都成立 → 成立。
