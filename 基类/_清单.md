# 基类清单

> **参考物索引，不是命令。** 作用：防止你和 AI 漏掉"本来该考虑的方面"。
> **怎么用**：准备阶段通读一遍 → 勾出相关的 → 打开抄约束 → 不适用的当场删。
>
> 一条重要原则：**基类记录的是"这类工作通常涉及哪些方面"，不是"你必须这样做"。**
> 用了发现不对，直接在具体工作区里删掉，不要硬套；**踩到新坑就补进对应基类的「易错点」。**

## 翻基类的正确姿势

1. **先看「通常涉及哪些方面」** —— 这一节是清单的全部价值所在。
   漏东西通常不是漏了细节，是漏了"没想到要考虑这个"。
2. 再看「默认约束」—— 挑适用的抄进工作区的 `GLOBAL_WORKFLOW.md`。
3. **「易错点」是历史积累，不是穷举。** 空着很正常，说明还没踩过。

---

## 基类之间怎么组合

基类可以叠加，而且**经常需要叠加**：

| 场景 | 组合 |
|---|---|
| 写课程设计报告 + 交代码 | `基类-文档` + `基类-代码` + `基类-课程作业` |
| Unity 毕设 | `基类-Unity` + `基类-代码` + `基类-文档` |
| 仿真实验出论文 | `基类-实验` + `基类-文档` |
| 纯资料整理 | `基类-文档` |

**组合时注意冲突**：两个基类给了矛盾的默认约束，以具体工作区里写的为准，并在准备阶段就裁决掉。
